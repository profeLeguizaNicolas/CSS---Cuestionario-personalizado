CSS - Cuestionario personalizado.

En esta actividad, los alumnos deberán aplicar estilos CSS al cuestionario desarrollado previamente en HTML. El sitio deberá contar con una apariencia agradable y moderna, utilizando colores, tipografías, márgenes, rellenos, bordes y espaciados para mejorar la presentación de todos los elementos. Además, el botón de inicio y el botón Enviar deberán incorporar un efecto visual al pasar el cursor sobre ellos hover, logrando un diseño ordenado y uniforme. 

Cada alumno deberá personalizar el diseño según el tema elegido en la etapa1 (por ejemplo, si el tema es Batman, usar colores relacionados con la saga).
Ejemplo de colores:
Tema Primer color Segundo color
🦇 Batman #1C1C1C (Negro) #F6C700 (Amarillo)
🃏 Joker #5A2D82 (Violeta) #3FA34D (Verde)
🦅 Pingüino #000000 (Negro) #FFFFFF (Blanco)
❓ Acertijo #2E8B57 (Verde) #1C1C1C (Negro)

Requisitos técnicos.

  • Crear un archivo llamado style.css y vincularlo en los tres documentos HTML index.html, cuestionario.html, resultado.html.
  • No se debe usar estilos inline (style="..."), todo debe estar en el archivo CSS.
  • Usar selectores de clases y elementos.


Cuestionario de ejemplo.



Ayuda:
Colores y fondos
  • Colocar un color o imagen de fondo relacionado con el tema. Usar una paleta coherente (2 o 3 colores principales como máximo).
Ejemplo de colores de fondo: 
body{
    background-color: #0d0d0d;
    color: white;
}
Ejemplo de imagen de fondo: 
body{
    background-image: url(ruta);
    background-size: cover;
    background-repeat: no-repeat;
}


Botones:
  • Personalizar los botones para que sean claros y atractivos. Agregar efector hover (Cuando el usuario pasa el mouse encima).
Ejemplo: 
button{
    background-color: #ffcc00;
    border: none;
    padding: 10px 20px;
    border-radius: 8px;
    font-size: 1em;
    cursor: pointer;
}

button:hover{
    background-color: #ffd633;
}


Preguntas.
  • Organizar las preguntas dentro de cajas o tarjetas. Usar border, sombras o fondos suaves para distinguirlas.
Ejemplo: 
fieldset{
    border: 2px solid #555;
    border-radius: 10px;
    padding: 15px;
    margin-bottom: 20px;
    background-color: rgba(255, 255, 255, 0.5);
}

legend{
    font-wight: bold;
    color: #ffcc00;
}


Centrado de tablas.
Ejemplo: 
table{
    margin: auto;
